1. 소음 유형 분류
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
A. 진동음 (웅웅/덜덜): 실외기 진동, 고정 볼트 이완
B. 딸깍음 (틱틱): 기동·정지 시 플라스틱 열팽창
C. 쉬익 소리 (가스음): 냉매 유동음 — 정상 범위
D. 끼익/마찰음: 팬 베어링 마모 또는 팬 날개 이물질

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2. 유형별 조치
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[A] 진동음
 → 실외기 수평 확인 및 레벨 조정
 → 고정 볼트 토크 확인 (규정 토크: 20 N·m)
 → 방진 패드 상태 확인 및 교체 (HAC-PAD-VIB)

[B] 딸깍음
 → 기동·정지 시 정상 현상으로 고객 안내
 → 과도한 경우 실내기 커버 고정 클립 확인

[C] 가스음
 → 냉매 유동 정상 현상 — 고객 안내 후 종결
 → 심한 경우 냉매량 확인 (과충전 가능성)

[D] 마찰음
 → 팬 날개 이물질 제거 (전원 차단 필수)
 → 팬 베어링 마모 시 팬 모터 교체
   · 실내기 팬 모터: HAC-FAN-INDOOR
   · 실외기 팬 모터: HAC-FAN-OUTDOOR

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
3. 야간 저소음 모드 설정 안내
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
삼성 스마트싱스 앱 → 에어컨 설정 → 취침 모드 ON
: 팬 속도 자동 저감, 저소음 운전 설정
: 취침 모드 시 소비전력 약 15% 절감

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
