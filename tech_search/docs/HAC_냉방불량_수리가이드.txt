1. 증상 확인 절차
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1-1. 현장 도착 후 설정 온도 및 운전 모드 확인
1-2. 실내기 흡입구·토출구 온도 차이 측정 (정상: 8~12°C 차이)
1-3. 실외기 작동 여부 육안 확인 (팬 회전, 컴프레서 소음)
1-4. 고압·저압 게이지 압력 측정

정상 압력 기준 (R410A 냉매):
 - 저압: 0.8~1.0 MPa (여름 기준)
 - 고압: 2.4~2.8 MPa (여름 기준)

2. 원인별 조치 방법
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[원인 A] 냉매 부족 (저압 0.6 MPa 이하)
 → 가스 누설 부위 확인 (비눗물 테스트 또는 전자식 검지기)
 → 누설 부위 수리 후 냉매 재충전
 → R410A 냉매 충전량: 실외기 명판 표시량 기준
 → 재충전 후 저압 0.85~0.95 MPa 확인

[원인 B] 실내기 필터 막힘
 → 필터 청소 또는 교체
 → 필터: 2주 1회 청소 권장 안내

[원인 C] 실외기 컨덴서 코일 오염
 → 고압 세척기로 코일 청소 (전원 차단 후)
 → 청소 후 성능 재측정

[원인 D] 컴프레서 불량
 → 컴프레서 운전 전류 측정 (정격 대비 ±10% 이내 정상)
 → 과전류 또는 무전류 시 컴프레서 교체 검토
 → 교체 부품번호: 서비스 파트 카탈로그 HAC-COMP 참조

[원인 E] 팽창밸브(EEV) 불량
 → 팽창밸브 개도 확인 (디지털 서비스 툴 연결)
 → 정상 개도: 350~450 pulse (냉방 풀부하 기준)
 → 개도 불량 시 EEV 교체
