1. 점검 주기
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
월간 점검 (매월 1회):
 - 필터 청소 및 상태 확인
 - 응결수 배수 상태 확인
 - 제어판 경보 이력 확인

분기 점검 (3개월 1회):
 - 냉매 압력 측정
 - 전기 접속부 절연 저항 측정
 - 팬 벨트 장력 및 마모 상태 (덕트형)
 - 열교환기 코일 청소

반기 점검 (6개월 1회):
 - 컴프레서 오일 샘플 분석
 - 전체 배관 가스 누설 검사
 - 안전 장치 (고압 차단, 저압 차단) 동작 테스트

연간 점검 (1년 1회):
 - 냉매 전량 회수 후 진공 테스트 및 재충전
 - 냉동기유 교환 (5,000시간 이상 운전 시)
 - 인버터 및 제어 보드 점검
 - 전체 시스템 성능 측정 (냉방 능력, COP)

2. 분기 점검 상세 체크리스트
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[ 전기 점검 ]
□ 주전원 전압 측정 (정격 ±10% 이내)
□ 운전 전류 측정 (컴프레서·팬 각각)
□ 절연 저항 측정: 컴프레서 단자 대지 간 1 MΩ 이상
□ 접지 저항: 100 Ω 이하

[ 냉동 사이클 점검 ]
□ 저압 (흡입 압력): R410A 기준 0.7~1.0 MPa
□ 고압 (토출 압력): R410A 기준 2.3~2.8 MPa
□ 토출 가스 온도: 90°C 이하
□ 과냉도: 5~10°C
□ 과열도: 5~10°C

[ 기계 점검 ]
□ 컴프레서 진동·소음 이상 없음
□ 팬 모터 진동·소음 이상 없음
□ 배관 고정 상태 이상 없음
□ 배수 펌프 및 드레인 라인 막힘 없음

3. 이상 조치 기준
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
알람 코드 E101: 고압 차단 → 응축기 코일 청소, 팬 이상 확인
알람 코드 E102: 저압 차단 → 냉매 부족 확인, 누설 점검
알람 코드 E201: 컴프레서 과부하 → 운전 전류 측정, 컴프레서 점검
알람 코드 E301: 통신 이상 → 실내외기 간 통신 케이블 확인
알람 코드 E401: 팬 모터 이상 → 팬 모터 교체 (CAC-FAN-OUTDOOR-L)

4. 계약 유형별 대응 범위
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
기본 보증: 부품 불량에 의한 수리 무상
PM 계약 (연간): 정기 점검 + 긴급 출동 (24시간 이내) + 소모품 교체
PM 플러스 계약: PM 계약 + 주요 부품 교체 포함 (컴프레서 제외)
풀 커버 계약: 모든 수리 비용 포함 (컴프레서 포함)
