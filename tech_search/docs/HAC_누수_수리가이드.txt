2. 원인 진단
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[원인 A] 드레인 팬 막힘
 확인: 드레인 팬 직접 육안 확인
 현상: 이끼, 슬라임, 이물질로 배수 구멍 막힘
 조치: 드레인 팬 탈거 후 고압 세척, 배수 구멍 관통 확인

[원인 B] 드레인 호스 역구배 또는 막힘
 확인: 배수 호스 전체 경로 확인
 현상: 호스 꺾임 또는 역경사 → 배수 불량
 조치: 호스 경로 수정 (3~5도 이상 하향 구배 확보)
       막힘 시 와이어 또는 고압 에어로 관통

[원인 C] 실내기 기울기 불량
 확인: 수평계로 실내기 수평 측정
 현상: 드레인 팬 반대 방향으로 기울어져 물 넘침
 조치: 벽 브라켓 재조정, 실내기 수평 재설치
       허용 기울기: 배수 방향으로 1~3도

[원인 D] 냉매 부족에 의한 증발기 결빙 후 해빙
 확인: 증발기 코일 결빙 여부 운전 중 확인
 현상: 코일 결빙 → 결빙이 녹으며 대량 누수
 조치: 필터 청소 후 재운전, 냉매 압력 측정
       냉매 부족 시 → HAC-RM-001 (냉방불량 가이드) 참조

[원인 E] 관통 슬리브 단열 불량
 확인: 배관 관통 부위 단열 상태 확인
 현상: 단열재 손상 → 결로수 발생
 조치: 단열 테이프(HAC-INS-TAPE) 재시공

3. 여름철 집중 발생 주의사항
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- 7~8월 고온 다습 시 결로 과다로 드레인 처리 용량 초과 발생 가능
- 장기 미사용 제품 재가동 시 드레인 팬 슬라임 다량 발생
- 예방: 시즌 전 (5~6월) 드레인 팬 청소 권장 안내
